# Code of Conduct

This is a learning space.

Be kind to beginners, domain experts, and people trying AI tools for the first time. Questions are welcome, even when they feel basic.

Expected behavior:

- Use welcoming language.
- Respect different skill levels.
- Critique ideas and materials, not people.
- Avoid sharing private data or confidential examples.
- Help keep discussions practical and useful.

Unacceptable behavior:

- Harassment, insults, or personal attacks
- Sharing someone else's private information
- Dismissing beginners for not knowing technical terms
- Posting spam or unrelated promotion

If something feels off, open an issue or contact the repository maintainer through GitHub.
