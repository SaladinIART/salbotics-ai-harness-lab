# Contributing

Thanks for helping make this learning hub useful.

This repo welcomes:

- Beginner questions
- Better plain-English explanations
- Domain examples
- Worksheet improvements
- Small demo ideas
- Corrections to confusing wording

## Contribution Principles

- Keep never-coders in mind first.
- Prefer short examples over abstract theory.
- Avoid private client data, private notes, or confidential screenshots.
- Make source material easy to reuse in talks, classrooms, and workshops.
- Keep the Salbotics imprint soft and respectful.

## Before Opening a Pull Request

1. Check that your change does not include secrets, private notes, or generated lock files.
2. Make sure Markdown links work.
3. Use plain English where possible.
4. Add Malay-friendly explanations only when they help understanding.
