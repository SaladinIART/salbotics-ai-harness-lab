# Episode 2: Lessons From Real Projects

This episode turns patterns from past Salbotics work into public-safe tutorials for non-technical builders.

The goal is not to publish private project details. The goal is to share reusable working habits:

- turn vague ideas into clear AI work orders
- give AI enough context without exposing sensitive material
- stop rabbit holes with checkpoints
- test output in plain language before trusting it
- redact real experience into safe public lessons

## Public-Safe Boundary

Use anonymized patterns only.

Allowed:

- lessons learned from building local tools, demos, docs, workflows, and tutorials
- fake examples, fake names, fake numbers, and generic project categories
- reusable prompt cards, worksheets, checklists, and review habits
- public-safe phrases such as "from past projects" or "from building local tools"

Not allowed:

- client names, real accounts, private repo paths, private screenshots, or personal notes
- credentials, buyer data, commercial strategy, internal product design, or operational numbers
- copied source from private repos
- claims about external tools, pricing, or current product behavior unless verified before publish

See the [public safety map](public-safety-map.md) before adding examples.
