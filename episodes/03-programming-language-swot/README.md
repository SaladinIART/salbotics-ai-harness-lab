# Episode 3: Programming Language SWOT

This module teaches programming languages as a harness engineering decision for
non-technical AI explorers, students, and anyone already lost in AI tool rabbit
holes.

The reader should not ask:

```text
Which programming language is best?
```

The reader should ask:

```text
What am I trying to build, what context am I in, what path should I follow,
how will I checkpoint progress, and what counts as done?
```

## Teaching Goal

Help readers understand what major programming languages are for in layman's
terms, why AI tools often expose them to confusing code stacks, and how to pick
a practical learning path without trying to learn everything at once.

## Core Message

Do not learn every language equally. Learn what each language is usually for,
start with a small useful stack, then specialize only when the project needs it.

Recommended starting stack:

1. Python for AI, data, automation, and fast prototypes.
2. HTML, CSS, and JavaScript for understanding web pages and interfaces.
3. TypeScript later for safer serious web apps.
4. SQL for databases and business data.
5. Bash/Shell for command-line and deployment literacy.
6. Git/GitHub for saving work, comparing changes, and sharing proof.

## Module Path

1. Start with the [human-readable full guide](language-swot-report.html).
2. Use the [Markdown source notes](language-swot-report.md) for copying,

3. Explain why language rankings are signals, not commandments.
4. Group languages by job: AI, web, data, backend, systems, mobile, research,
   games, blockchain, and legacy maintenance.
5. Use SWOT to compare tradeoffs in plain language.
6. End with practical exercises and sample answers.

## Main Language Groups

| Group | Languages | What they help readers understand |
|---|---|---|
| AI and automation | Python, SQL, Bash | Data, scripts, models, evaluation, glue work |
| Web and product | HTML/CSS, JavaScript, TypeScript | User interfaces, APIs, dashboards, app delivery |
| Backend and enterprise | Java, C#, Go, PHP | Services, business systems, cloud platforms |
| Systems and hardware | C, C++, Rust, Zig | Memory, performance, embedded, infrastructure |
| Mobile | Kotlin, Swift, Dart | Android, iOS, cross-platform apps |
| Research and engineering | R, MATLAB, Julia, Scala | Statistics, simulation, data engineering |
| Specialist niches | Ruby, Lua, Elixir, Solidity | Rails, games, realtime systems, smart contracts |
