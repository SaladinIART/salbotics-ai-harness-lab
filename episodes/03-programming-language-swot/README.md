# Episode 3: Programming Language SWOT

This module teaches programming languages as a harness engineering decision.
Students should not ask, "Which language is best?" They should ask:

```text
What am I trying to build, what context am I in, what path should I follow,
how will I checkpoint progress, and what counts as done?
```

## Teaching Goal

Help students understand the functionality, applications, strengths,
weaknesses, opportunities, and threats of major programming languages so they
can choose a practical learning path for the next 5-10 years.

## Core Message

Do not learn every language equally. Learn a small stack that lets you build
real projects, then specialize when the project needs it.

Recommended starting stack:

1. Python for AI, data, automation, and fast prototypes.
2. HTML, CSS, JavaScript, and TypeScript for web and product interfaces.
3. SQL for databases and business data.
4. Bash/Shell for automation and deployment literacy.
5. Java, C#, or Go for backend and enterprise depth.
6. C, C++, Rust, or Zig later for systems, robotics, and performance.

## Module Path

1. Start with the [full language SWOT report](language-swot-report.md).
2. Explain why language rankings are signals, not commandments.
3. Group languages by job: AI, web, data, backend, systems, mobile, research,
   games, blockchain, and legacy maintenance.
4. Use SWOT to compare tradeoffs.
5. End with a student roadmap and portfolio proof.

## Main Language Groups

| Group | Languages | What they help students understand |
|---|---|---|
| AI and automation | Python, SQL, Bash | Data, scripts, models, evaluation, glue work |
| Web and product | HTML/CSS, JavaScript, TypeScript | User interfaces, APIs, dashboards, app delivery |
| Backend and enterprise | Java, C#, Go, PHP | Services, business systems, cloud platforms |
| Systems and hardware | C, C++, Rust, Zig | Memory, performance, embedded, infrastructure |
| Mobile | Kotlin, Swift, Dart | Android, iOS, cross-platform apps |
| Research and engineering | R, MATLAB, Julia, Scala | Statistics, simulation, data engineering |
| Specialist niches | Ruby, Lua, Elixir, Solidity | Rails, games, realtime systems, smart contracts |
