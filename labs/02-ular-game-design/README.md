# Lab 02: Ular Game Design

This is a planned public-safe lab inspired by "Ular yg Mengular", a snake-game idea.

No private game repo files are copied here. The future demo should be rebuilt as a small standalone learning exercise.

## Learning Goal

Use harness engineering to design a tiny game without expanding into an endless feature list.

## Scope

First public version:

- One snake
- One food item
- Score
- Collision rules
- Restart
- Simple keyboard or touch controls
- One short playtest checklist

Not in first version:

- Accounts
- Online leaderboard
- Multiplayer
- Complex skins
- Large asset pipeline
- Story mode

## Harness Lesson

Game ideas are fun, so they drift easily.

The harness protects the first version:

```text
Goal + Rules + Player Input + Playtest Checkpoints + Done Criteria
```
