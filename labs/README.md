# Labs

Labs are small practical exercises that turn the talk ideas into repeatable workflows.

Each lab should include:

- A plain-English goal
- A harness prompt
- A worksheet
- Checkpoints
- Done criteria
- Notes for future improvement

Available labs:

- [Lab 02: Ular Game Design](02-ular-game-design/README.md) - public-safe snake-game redesign with a completed Pyxel CP11 roguelite prototype and [playtest tutorial](02-ular-game-design/tutorial-cp11-playtest.md).
- [Lab 03: Underdog Racing](03-underdog-racing/README.md) - Phaser + TypeScript top-down pixel racing prototype with CP7 Street Underdog Cup championship loop, one-rival AI duel, event gates, car upgrades, difficulty selection, and [dedicated learning tutorials](03-underdog-racing/tutorials/README.md).
